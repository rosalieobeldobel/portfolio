# Rosalie Obeldobel –  Portfolio

Dies ist mein persönliches Portfolio, entwickelt mit **React** und **Next.js**.  
Es zeigt meine Projekte, Designarbeiten und Fähigkeiten im Bereich **UI/UX, Webentwicklung und visueller Kommunikation**.

## 🚀 Features
- Präsentation meiner **Projekte und Designs**
- Nutzung von **React-Komponenten** für modulare Entwicklung
- **Next.js Routing** für schnelle Navigation zwischen Seiten
- Einfache Erweiterung für zukünftige Projekte

## 🛠️ Technologien
- **Frontend:** React, Next.js, HTML, CSS, JavaScript, Typescript  
- **Design & Prototyping:** Figma
- **Versionierung:** Git, GitHub  

## 📂 Struktur
- /app - Next.js Seiten, Routing und CSS-Dateien
- /components - wiederverwendbare React-Komponenten
- /public - Bilder, Icons, statische Dateien

## ⚡ Nutzung
1. Repository klonen:  
```bash
git clone git@github.com:rosalieobeldobel/portfolio.git
```
2. Abhängigkeiten installieren
```bash
cd frontend
npm install --save-dev typescript @types/react @types/node
```
3. Entwicklungsserver starten
```bash
npm run dev
```
4. Portfolio lokal im Server anschauen<br>
http://localhost:3000

5. Portfolio direkt auf der Website anschauen<br>
https://portfolio-iota-ten-doq7ll6i8w.vercel.app/
